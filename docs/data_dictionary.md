# Data Dictionary

Describes every table and column in the dataset. Source: `database/schema.sql`,
generated by `simulator/event_generator.py`.

## users
| Column | Type | Description |
|---|---|---|
| user_id | INT (PK) | Unique identifier for a user |
| signup_date | DATE | Date the user first signed up |
| country | VARCHAR | User's country |
| device | VARCHAR | Primary device: desktop, mobile, tablet |
| acquisition_channel | VARCHAR | How the user found the product: organic, paid_ads, referral, content |

## accounts
| Column | Type | Description |
|---|---|---|
| account_id | INT (PK) | Unique identifier for an account |
| user_id | INT (FK → users) | Owner of the account |
| plan | VARCHAR | Plan at account creation: free, pro, enterprise |
| account_created_at | TIMESTAMP | When the account was created |

## subscriptions
| Column | Type | Description |
|---|---|---|
| subscription_id | INT (PK) | Unique identifier for a subscription |
| account_id | INT (FK → accounts) | Account the subscription belongs to |
| plan | VARCHAR | Subscribed plan: pro, enterprise |
| status | VARCHAR | trialing, active, canceled |
| started_at | TIMESTAMP | When the trial/subscription started |
| trial_end_at | TIMESTAMP | Scheduled end of the 14-day trial |
| canceled_at | TIMESTAMP | When the subscription was canceled (NULL if still active) |

## events
The heart of the dataset — one row per user action.

| Column | Type | Description |
|---|---|---|
| event_id | BIGINT (PK) | Unique identifier for an event |
| user_id | INT (FK → users) | User who triggered the event |
| event_timestamp | TIMESTAMP | When the event occurred |
| event_type | VARCHAR | See [event_taxonomy.md](event_taxonomy.md) for full list |
| feature | VARCHAR | Feature name, populated only when event_type = 'feature_used' |
| device | VARCHAR | Device at time of event |
| country | VARCHAR | Country at time of event |
| plan | VARCHAR | Plan at time of event |

## sessions
| Column | Type | Description |
|---|---|---|
| session_id | BIGINT (PK) | Unique identifier for a session |
| user_id | INT (FK → users) | User who had the session |
| started_at | TIMESTAMP | Session start time |
| ended_at | TIMESTAMP | Session end time |
| device | VARCHAR | Device used for the session |

## payments
| Column | Type | Description |
|---|---|---|
| payment_id | BIGINT (PK) | Unique identifier for a payment |
| subscription_id | INT (FK → subscriptions) | Subscription being billed |
| amount | NUMERIC(10,2) | Payment amount in USD |
| payment_date | DATE | Date of the billing attempt |
| status | VARCHAR | succeeded, failed |
